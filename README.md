# Ali Mohsen Maruf — Portfolio

A responsive, static portfolio for Ali Mohsen Maruf, a Geography and Environment undergraduate at Jahangirnagar University. It presents his GIS and spatial research interests, education technology work, selected projects, and contact details.

## Structure

- `index.html` contains the complete, server-rendered portfolio and structured profile data.
- `assets/css/style.css` contains the responsive visual system.
- `assets/js/script.js` provides project category filtering and in-page scroll helpers.
- `assets/images/` contains the site images and favicon.
- `robots.txt`, `sitemap.xml`, and `llms.txt` support crawler discovery and concise AI-readable site context.

## Run locally

Open `index.html` in a browser or serve this folder with any static web server. The site has no build step or package dependencies.
