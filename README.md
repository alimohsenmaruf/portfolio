# Ali Mohsen Maruf — Portfolio
Static one-page portfolio. Open `index.html` or serve the folder; no build step.
- `assets/js/script.js`: topographic contour hero (canvas), scroll-linked statement, copy-email, local clock.
- `assets/images/land-cover.svg`: schematic placeholder. Replace with your real QGIS export (PNG/JPG) and update the `<img>` in the "Reading the landscape" card.
